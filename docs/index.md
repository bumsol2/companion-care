## 문서 기여 가이드

### 문서 작성 원칙
- **간결함**: 필요한 정보만 명확하게 제공
- **최신성**: 변경 사항이 있을 때마다 관련 문서 업데이트
- **구조화**: 제목, 소제목, 목록 등을 활용하여 읽기 쉽게 구성
- **코드 예시**: 실제 사용 가능한 코드 스니펫 제공

### 마크다운 스타일 가이드
- 제목은 `#`, `##`, `###` 등의 수준으로 구분
- 코드 블록은 ``` 사용하여 언어 지정 (예: ```typescript)
- 표는 마크다운 테이블 문법 사용
- 중요 내용은 **굵게** 표시
