### ⚠ CRON / 이메일 발송 리스크
| 항목             | 조치                                                     |
|------------------|----------------------------------------------------------|
| CRON 동작 환경   | Vercel Scheduler만 사용할 것 (production only 설정)      |
| SMTP 인증        | Gmail App Password or Resend API로 대체 가능             |
| 로컬/클라우드 차이| CRON → 로그 남기기 / 실패 시 retry 로직 포함 예정        |
